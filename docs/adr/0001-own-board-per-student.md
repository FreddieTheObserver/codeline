# Each student fills their own Board; the Class Board is an aggregate

In the paper exercise the whole room built one program, but a class of 50 to 200 students and a program of about 12 Slots means many students hold the same Snippet.
On a single shared board, the first student to place a Snippet would fill its Slot and take the decision away from everyone else holding it, which defeats the point of the exercise: every student makes a real decision.
So each student places on their own Board, every Placement is judged and recorded (S1-LEC-09), and the projector shows the Class Board, which combines all Boards: a Slot lights up once anyone fills it correctly, shaded by how much of the class got it right.

## Considered options

- One shared board, first correct Placement wins: rejected because duplicate holders lose their decision.
- Exercises with at least as many Slots as students, so no Snippet is duplicated: rejected because it forces 50 to 200-line programs.
